# The Chef’s Scroll

A mobile app built with React Native and Expo for managing restaurant menus. Designed for chefs, food lovers, and hospitality professionals, it allows users to add, filter, edit, and remove menu items with ease.

---

##  Features

- **Home Screen**: Displays a hero image, welcome message, live stats, and a scrollable list of menu items.
- **Add Screen**: Form to input new dishes with validation and accessibility.
- **Filter Screen**: View dishes by course (Starters, Mains, Desserts).
- **Manage Screen**: Edit or remove items from the menu.
- **Bottom Tab Navigation**: Custom icons, styled headers, and responsive layout.

---

## Tech Stack

- React Native
- Expo
- React Navigation
- Context API
- TypeScript
- Ionicons
